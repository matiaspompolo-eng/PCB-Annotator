# PCB Annotator

Aplicación desarrollada en **Python** para el relevamiento, anotación y documentación de placas de circuito impreso (PCB).

Permite cargar una imagen de una PCB y agregar capas de información para identificar:

- 🔌 Pistas y conexiones
- 🔧 Componentes
- 🟢 Zonas de cobre
- 📍 Puntos de interés
- 📝 Anotaciones técnicas

## Funcionalidades

- Carga y exportación de imágenes
- Capas de anotación
- Trazado de pistas
- Resaltado de cobre
- Identificación de componentes
- Etiquetas, flechas y formas
- Zoom, rotación y ajuste de imagen
- Guardado y carga de capas

## Objetivo

Facilitar la **documentación de reparaciones y relevamientos de PCBs**, conservando información visual que pueda utilizarse posteriormente para diagnóstico y futuras reparaciones.

## Tecnología

**Python**
